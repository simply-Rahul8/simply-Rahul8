## Selected projects

1. **[Dual-LLM RAG Insight Engine](https://github.com/simply-Rahul8/Dual-LLM-RAG-based-Pipeline)**
   Problem: enterprise users needed accurate, grounded answers from large internal document collections.
   Solution: dual-LLM RAG with semantic chunking, hybrid search, query transformation, and reranking.
   Result: answer quality validated with RAGAS Faithfulness and Context Relevance metrics.

2. **[SHL Assessment Recommender](https://github.com/simply-Rahul8/shl-recommender-agent)**
   An LLM agent that helps recruiters pick the right SHL assessments. Two-call pipeline (intent classification, then grounded recommendations), MMR reranking over a FAISS index, strict Pydantic schemas, and a behavioral test suite covering prompt injection, schema compliance, and Recall@10.

3. **[3D Pose Estimation and Fatigue Detection](https://github.com/simply-Rahul8/3D-pose-estimation)** (bachelor's thesis)
   Problem: detecting physical fatigue in real time from human body movement.
   Solution: 3D pose pipeline using HRNet keypoints, SemGCN spatial and BiLSTM temporal modeling.
   Result: 93% classification accuracy at 30 FPS on a standard GPU.

4. **[Customer Feedback Analysis Tool](https://github.com/simply-Rahul8/Customer-Feedback-Analysis-Tool)**
   Problem: unstructured customer feedback was difficult to categorize and analyze at scale.
   Solution: hybrid LLM and rule-based pipeline for sentiment analysis and automated categorization.
   Result: sub-500ms latency insights surfacing recurring customer opinion trends.

5. **[Personal Data RAG Chatbot](https://github.com/simply-Rahul8/Personal-chatbot)**
   A privacy-first chatbot with local RAG using Streamlit, Ollama, LangChain, and a local FAISS vector store.
